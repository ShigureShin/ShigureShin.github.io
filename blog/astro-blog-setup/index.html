为什么选 Astro

静态站点生成器，构建时渲染，运行时零 JS。适合博客这种内容为主的场景。

技术栈

  • Astro 7（最新版）
  • Tailwind CSS v4（Vite 插件方式接入）
  • daisyUI v5（组件库）
  • TypeScript（严格模式）

配置驱动

所有可变内容写在 site.config.yaml 里，构建时解析为 TypeScript 常量，组件直接 import 使用。
